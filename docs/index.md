# Web Development Cheatsheet

Bienvenido a la **Web Development Cheatsheet**, una guía de referencia rápida, estructurada y en constante evolución sobre tecnologías de desarrollo web.

Este espacio está diseñado para servir como un apunte personal y una herramienta de consulta rápida para recordar conceptos clave, sintaxis y mejores prácticas en el desarrollo web.

## :lucide-layers: Tecnologías Disponibles

Actualmente, la documentación cubre los fundamentos estructurales y visuales de la web:

- **[HTML](html/01-introduction.md):** Etiquetas, semántica, enlaces, imágenes, formularios y contenedores.
- **[CSS](css/01-introduction.md):** Texto, Selectores, Box Model

## :lucide-milestone: Próximamente

Esta guía se encuentra en desarrollo activo. En el futuro, se expandirá para cubrir desarrollo interactivo y backend:

- **JavaScript:** Manipulación del DOM, eventos, asincronía (Promesas, Async/Await) y consumo de APIs.
- **Java:** Fundamentos del lenguaje, Programación Orientada a Objetos (POO), Colecciones y Manejo de errores.
- **SQL:** Diseño de bases de datos relacionales, consultas, uniones (JOINs) y normalización.
- **Spring Boot:** Creación de APIs REST, inyección de dependencias, conexión a bases de datos y seguridad.

## :lucide-lightbulb: Cómo usar esta guía

Puedes navegar por las diferentes secciones utilizando el menú lateral. Cada tema está diseñado para ser directo e ir al grano, acompañado de ejemplos de código, notas importantes y diagramas de resumen cuando resulta pertinente.
